# 🧱 XYZ Smart Contract

A simple and beginner-friendly Solidity smart contract designed to help you understand the basics of deploying and interacting with Ethereum smart contracts.  
This project serves as a minimal and clean example to get started with Solidity development using tools like [Remix](https://remix.ethereum.org), [Hardhat](https://hardhat.org), or [Foundry](https://book.getfoundry.sh/).

---

## 📜 Project Description

The **XYZ Smart Contract** is a minimalistic Solidity project built for learning and experimentation.  
It demonstrates how to deploy a contract without requiring any constructor inputs, while still providing interactive functions for users to engage with on the blockchain.  

The contract is ideal for beginners who want to:
- Learn how smart contracts work.
- Understand public variables and functions.
- Practice reading and writing data to the blockchain.

---

## ⚙️ What It Does

Once deployed, the **XYZ Smart Contract**:
- Stores a simple **welcome message**.
- Keeps a **counter** that anyone can increment or reset.
- Lets users **view data** directly from the blockchain without input fields.

This makes it perfect for first-time Solidity learners or developers exploring decentralized app (dApp) functionality.

---

## 🌟 Features

✅ **No Input Fields** – The contract deploys instantly without needing constructor parameters.  
✅ **Public Variables** – Easy to read directly from the blockchain.  
✅ **Counter Functionality** – Interact by incrementing and resetting a stored counter.  
✅ **Beginner-Friendly** – Simple, clean, and well-commented for quick learning.  
✅ **Fully Deployable** – Works seamlessly with Remix, Hardhat, or any EVM-compatible blockchain.
